## 📖 Sobre o Projeto / About the Project

Este é o repositório do meu **Portfólio Pessoal**, desenvolvido para ser o hub central de todo o meu ecossistema de projetos de software. Ele foi projetado com uma interface moderna, rápida e totalmente responsiva, com o objetivo de apresentar minha jornada profissional, minhas habilidades técnicas, certificações e os principais projetos que venho desenvolvendo (como aplicações Web, Mobile e soluções de automação e dados).

O portfólio possui **suporte a internacionalização (i18n)**, permitindo que os visitantes alternem dinamicamente entre **Português (PT-BR)** e **Inglês (EN-US)**, garantindo uma ótima acessibilidade para recrutadores e parceiros de todo o mundo.

---

## ✨ Funcionalidades Principais

- 🌍 **Internacionalização (i18n):** Suporte nativo para Português e Inglês, gerenciado de forma eficiente através de um dicionário customizado em TypeScript.
- 🎨 **Design Moderno & Responsivo:** Construído utilizando **Tailwind CSS**, garantindo uma experiência visual imersiva e consistente em dispositivos móveis, tablets e desktops (incluindo Dark Mode e micro-animações).
- 📂 **Galeria Dinâmica de Projetos:** Sistema inteligente de projetos separados por categorias (Web, Mobile, Backend, Dados, Design). Cada projeto conta com descrições detalhadas, tags de tecnologias e uma galeria de imagens para demonstração.
- 📜 **Seção de Certificados:** Um acervo visual da minha jornada acadêmica e aperfeiçoamento contínuo em tecnologia e liderança.
- ✉️ **Formulário de Contato:** Interface amigável para envio de mensagens diretamente pelo portfólio.
- ⚡ **Alta Performance:** Construído sob o ecossistema do **Vite**, oferecendo carregamento rápido e navegação fluida de uma Single Page Application (SPA).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as ferramentas e boas práticas modernas do ecossistema Frontend:

- **[React](https://reactjs.org/)** (v19) - Biblioteca principal para a construção da interface do usuário baseada em componentes.
- **[TypeScript](https://www.typescriptlang.org/)** - Superset do JavaScript que adiciona tipagem estática e maior segurança ao código.
- **[Vite](https://vitejs.dev/)** - Ferramenta de build extremamente rápida que proporciona um ambiente de desenvolvimento ágil.
- **[Tailwind CSS](https://tailwindcss.com/)** - Framework utilitário de CSS usado para a estilização ágil e responsiva de toda a aplicação.
- **[React Router DOM](https://reactrouter.com/)** - Gerenciamento robusto de rotas para navegação sem recarregamento da página.
- **[Material Symbols](https://fonts.google.com/icons)** - Biblioteca de ícones vetoriais modernos do Google.

## ⚙️ Como Executar o Projeto Localmente

Siga os passos abaixo para rodar o projeto em sua máquina:

### 1. Pré-requisitos
Certifique-se de ter o **Node.js** (versão 18+) instalado.

### 2. Clonando o repositório
```bash
git clone https://github.com/LeonHauck/Leon-Hauck-Portfolio.git
```

### 3. Instalando as dependências
Acesse a pasta do projeto e instale as dependências via npm:
```bash
cd Leon-Hauck-Portfolio
npm install
```

### 4. Iniciando o servidor de desenvolvimento
```bash
npm run dev
```

O aplicativo estará disponível no seu navegador, por padrão em `http://localhost:5173`.

### 5. Build para Produção
Para compilar o código otimizado para produção:
```bash
npm run build
```
